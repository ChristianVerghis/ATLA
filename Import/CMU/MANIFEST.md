# CMU mocap clips (pre-converted FBX)

Source: CMU Graphics Lab Motion Capture Database via HuggingFace `gbionics/cmu-fbx`
(binary FBX, root node `hip`). License: free for any use including commercial
products; the only restriction is reselling the raw data itself. Credit appreciated:
"Data obtained from mocap.cs.cmu.edu — the database was created with funding from
NSF EIA-0196217."

Element mapping: 12_04 = tai chi (WATER). 135_* = karate kata/techniques (EARTH/FIRE).
144_* = punch/kick/block/lunge sequences (FIRE/EARTH). 85/87/88_* = breakdance,
flips, cartwheels, handstands (AIR). Known caveat: CMU data is noisy — expect
foot-slide cleanup during retarget (plan item 4.3).
